# 语音输入法 - 用户手册

## 简介

语音输入法是一款基于Tauri 2.0的桌面语音输入法应用，支持实时语音转文字，帮助用户提高文本输入效率。

## 功能特性

- 🎙️ **实时语音转文字** - 边说边转写，延迟低至1-2秒
- 🌐 **在线/离线双模式** - 在线使用百度语音API，离线使用faster-whisper
- 🌍 **多语言支持** - 普通话、英语、中英文混合识别
- ✍️ **智能纠错** - 自动修正标点符号和常见错误
- 🎨 **简洁界面** - 极简设计，易于使用
- 🖥️ **跨平台** - 支持 Windows、macOS、Linux

## 安装

### Windows

1. 下载 `语音输入法_0.1.0_x64-setup.exe`
2. 双击运行安装程序
3. 按照提示完成安装

### macOS

1. 下载 `语音输入法_0.1.0_x64.dmg`
2. 打开DMG文件
3. 将应用拖入Applications文件夹

### Linux

1. 下载 `语音-input-method_0.1.0_amd64.AppImage`
2. 添加执行权限：`chmod +x 语音-input-method_0.1.0_amd64.AppImage`
3. 运行应用

## 快速开始

### 首次使用

1. 启动应用后，您会看到简洁的界面
2. 首次使用需要配置百度语音识别API密钥
3. 点击"设置" → "识别设置" → 填入API密钥

### 开始录音

1. 点击中央的录音按钮
2. 允许麦克风权限
3. 开始说话，识别结果会实时显示

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 开始/停止录音 |
| `Ctrl+C` | 复制识别文本 |
| `Ctrl+L` | 清空识别文本 |

## 功能说明

### 识别模式

- **自动模式** - 根据网络状态自动选择在线/离线模式
- **在线模式** - 使用百度语音识别API，需要网络连接
- **离线模式** - 使用本地faster-whisper模型，无需网络

### 语言选择

- **普通话（加强标点）** - 支持中英文混合识别
- **普通话（弱标点）** - 中文普通话识别
- **英语** - 英文识别
- **中文多方言** - 支持多种中文方言

### 历史记录

- 识别结果自动保存到历史记录
- 支持搜索历史记录
- 支持删除单条记录
- 支持清空所有记录
- 支持从历史记录加载文本

### 设置选项

- 默认语言
- 智能纠错开关

#### 录音设置

#### 界面设置

## 离线识别

### 安装Python依赖

离线识别功能需要Python环境和faster-whisper库：

```bash
# 安装Python 3.8+
# 安装faster-whisper
pip install faster-whisper
```

### 下载模型

首次使用离线识别时，会自动下载模型文件。模型大小可选：

- **tiny** - 最小模型，速度快，准确率低
- **base** - 基础模型，平衡速度和准确率
- **small** - 小型模型，准确率较好
- **medium** - 中型模型，准确率高（推荐）
- **large-v3** - 大型模型，准确率最高

## 常见问题

### Q: 识别不准确怎么办？

A: 
1. 确保网络连接稳定（在线模式）
2. 说话清晰，语速适中
3. 减少背景噪音
4. 尝试切换识别模式

### Q: 无法录音怎么办？

A:
1. 检查麦克风权限
2. 确保麦克风设备正常
3. 重启应用

### Q: 离线模式无法使用？

A:
1. 确保已安装Python 3.8+
2. 确保已安装faster-whisper：`pip install faster-whisper`
3. 检查网络连接（首次需要下载模型）

### Q: 如何获取API密钥？

A:
1. 访问 https://cloud.baidu.com/
2. 注册并完成实名认证
3. 进入控制台 → 语音技术 → 创建应用
4. 获取APP_ID、API_KEY、SECRET_KEY
